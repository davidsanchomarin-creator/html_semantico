Wireframe semántico

Analiza un wireframe y construye visualmente la estructura de elementos HTML.

1. Cargar wireframe

Selecciona una imagen para comenzar. Solo es necesario cargarla una vez.

2. Seleccionar elementos HTML

Al elegir contenido se ignora el campo de clase.
main

Representa el contenido principal y único de la página. Debe contener la información central del documento, excluyendo cabeceras, navegación y pies comunes. Normalmente hay un solo main visible por página.

Al cambiar el contenedor se limpia automáticamente la clase para facilitar el siguiente dibujo.
